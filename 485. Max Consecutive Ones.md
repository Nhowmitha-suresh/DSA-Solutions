# LeetCode 485 - Max Consecutive Ones

## Problem

Given a binary array `nums`, return the maximum number of consecutive `1`s in the array.

### Example

**Input**

```text
nums = [1,1,0,1,1,1]
```

**Output**

```text
3
```

**Explanation**

The longest sequence of consecutive `1`s is:

```text
1 1 0 1 1 1
      └─────┘
        Length = 3
```

---

# Intuition

We only need to count consecutive `1`s.

- If we see a `1`, we continue the current sequence.
- If we see a `0`, the current sequence ends.
- Before starting a new sequence, compare the current sequence length with the maximum found so far.
- At the end of the array, check one last time because the array may end with `1`s and there may not be a `0` to update the answer.

---

# Algorithm

1. Initialize two variables:
   - `currentCount = 0` → stores the length of the current sequence of consecutive `1`s.
   - `maxCount = 0` → stores the maximum consecutive `1`s found so far.

2. Traverse the array.

3. If the current element is `1`:
   - Increment `currentCount`.

4. Otherwise (the current element is `0`):
   - The current sequence has ended.
   - Update `maxCount` using:
     ```java
     maxCount = Math.max(maxCount, currentCount);
     ```
   - Reset
     ```java
     currentCount = 0;
     ```
     because a `0` breaks the consecutive sequence. Any new sequence of `1`s must start after this `0`, so the previous count cannot continue.

5. After the loop finishes, return:
   ```java
   Math.max(maxCount, currentCount);
   ```
   This final comparison is necessary because if the array ends with `1`s, the `else` block is never executed, so `maxCount` would not be updated for the last sequence.

```text
nums = [1,1,0,1,1,1]

currentCount = 0

1

Loop ends

```

---

# Why do we reset `currentCount = 0`?

Consider the array:

```text
[1,1,0,1,1]
```

After reading the first two `1`s:

```text
currentCount = 2
```

When we encounter `0`:

```text
1 1 0 1 1
    ^
```

the consecutive sequence is broken.

The previous sequence has already been counted, so we update:

```java
maxCount = Math.max(maxCount, currentCount);
```

Now we must start counting from the next element.

If we **do not reset**:

```text
currentCount = 2
```

then the next `1`s would incorrectly continue the previous sequence:

```text
2 -> 3 -> 4
```

which would treat

```text
1 1 0 1 1
```

as

```text
1 1 1 1
```

This is incorrect because the `0` breaks the sequence.

Therefore, we reset:

```java
currentCount = 0;
```

to start counting a completely new sequence after the `0`.

---

# Why do we return `Math.max(maxCount, currentCount)`?

Consider:

```text
nums = [1,1,1]
```

There is **no `0`**.

So the `else` block never runs.

```text
currentCount = 3
maxCount = 0
```

If we simply returned:

```java
return maxCount;
```

the answer would be:

```text
0
```

which is wrong.

Therefore, after the loop we compare one final time:

```java
return Math.max(maxCount, currentCount);
```

This ensures the last sequence is also considered.

---

# Java Code

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {

        int currentCount = 0;
        int maxCount = 0;

        for (int num : nums) {

            if (num == 1) {
                currentCount++;
            } else {
                maxCount = Math.max(maxCount, currentCount);
                currentCount = 0;
            }
        }

        return Math.max(maxCount, currentCount);
    }
}
```

---

# Complexity Analysis

**Time Complexity:** `O(n)`

- The array is traversed exactly once.

**Space Complexity:** `O(1)`

- Only two integer variables are used.
