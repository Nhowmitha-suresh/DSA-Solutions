## **1. MERGE INTERVALS**

Merge all overlapping intervals.

Example:

```
Input:  [[1,3], [2,6], [8,10], [15,18]]
Output: [[1,6], [8,10], [15,18]]
```

## **2. Algorithm**

1. Sort intervals by start.
2. Keep `start` and `end` for the current interval.
3. If `nextStart <= end`, intervals overlap → update `end`.
4. Otherwise, add current interval and start a new one.
5. Add the last interval.

## **3. Code**

```java
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {

        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

        List<int[]> result = new ArrayList<>();

        int start = intervals[0][0];
        int end = intervals[0][1];

        for (int i = 1; i < intervals.length; i++) {

            if (intervals[i][0] <= end) {
                end = Math.max(end, intervals[i][1]);
            } else {
                result.add(new int[]{start, end});

                start = intervals[i][0];
                end = intervals[i][1];
            }
        }

        result.add(new int[]{start, end});

        return result.toArray(new int[result.size()][]);
    }
}
```

## **4. Key Keywords**

- `sort` → sort by start
- `start` → current interval start
- `end` → current interval end
- `nextStart <= end` → overlap
- `Math.max()` → extend interval
- `result.add()` → save interval
- `else` → start new interval

## **5. Remember**

```
Overlap → Extend
No overlap → Save + Start New
```
