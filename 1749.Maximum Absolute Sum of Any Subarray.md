
## LeetCode 1749: Maximum Absolute Sum of Any Subarray

### Question
Given an integer array `nums`, find the maximum possible absolute sum of any subarray (a non-empty contiguous part of the array).

The absolute sum of a subarray is the absolute value of the sum of its elements.

### Java Solution
```java
class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int curmax = nums[0];
        int maxsum = nums[0];

        int curmin = nums[0];
        int minsum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            curmax = Math.max(nums[i], nums[i] + curmax);
            maxsum = Math.max(maxsum, curmax);

            curmin = Math.min(nums[i], nums[i] + curmin);
            minsum = Math.min(curmin, minsum);
        }

        return Math.max(maxsum, Math.abs(minsum));
    }
}
```

### Approach
1. Use Kadane's algorithm to find the maximum subarray sum (`maxsum`).
2. Use a similar approach to find the minimum subarray sum (`minsum`).
3. The maximum absolute sum is the larger of the maximum subarray sum and the absolute value of the minimum subarray sum.
4. Return `Math.max(maxsum, Math.abs(minsum))`.

### Complexity
- Time: `O(n)`
- Space: `O(1)`
