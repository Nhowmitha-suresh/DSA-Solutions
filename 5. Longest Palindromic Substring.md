# 5. Longest Palindromic Substring

## Question

Given a string `s`, return the longest palindromic substring in `s`.

A palindrome is a string that reads the same forward and backward.

### Example

Input:
`s = "babad"`

Output:
`"bab"`

Note: `"aba"` is also a valid answer.

## Algorithm

1. Consider every character as the center of a palindrome.
2. Check for an odd-length palindrome using `(i, i)`.
3. Check for an even-length palindrome using `(i, i + 1)`.
4. Expand left and right while the characters are equal.
5. Compare the palindrome length with the current answer.
6. Store the longest palindrome.
7. Return the answer.

## Complexity

- Time: `O(n²)`
- Space: `O(1)`

## Code

```java
class Solution {

    public String longestPalindrome(String s) {

        String ans = "";

        for (int i = 0; i < s.length(); i++) {

            String odd = expand(s, i, i);
            String even = expand(s, i, i + 1);

            if (odd.length() > ans.length()) {
                ans = odd;
            }

            if (even.length() > ans.length()) {
                ans = even;
            }
        }

        return ans;
    }

    private String expand(String s, int left, int right) {

        while (left >= 0 &&
               right < s.length() &&
               s.charAt(left) == s.charAt(right)) {

            left--;
            right++;
        }

        return s.substring(left + 1, right);
    }
}
```

## Key Point

A palindrome is symmetric around its center.

- `(i, i)` → Odd-length palindrome
- `(i, i + 1)` → Even-length palindrome

For every index, expand in both ways and keep the longest palindrome.
