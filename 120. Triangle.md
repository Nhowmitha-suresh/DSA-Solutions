
# LeetCode 120: Triangle

**Difficulty:** Medium  
**Topics:** Dynamic Programming (DP)

## Problem
Given a triangle array, find the minimum path sum from top to bottom. From each element, you can move to either the same index or the next index in the row below.

**Example:**
```text
Input:  [[2],[3,4],[6,5,7],[4,1,8,3]]
Output: 11

Explanation: 2 → 3 → 5 → 1 = 11
```

##  Algorithm
1. Create a `dp` array of size `n × n`.
2. Copy all triangle elements into `dp`.
3. Start from the second-last row and move upward.
4. For each element, add the minimum of its two children:
   `dp[i][j] += Math.min(dp[i+1][j], dp[i+1][j+1])`
5. Return `dp[0][0]`, which contains the minimum path sum.

##  Java Solution
```java
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();
        int[][] dp = new int[n][n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j <= i; j++) {
                dp[i][j] = triangle.get(i).get(j);
            }
        }

        for (int i = n - 2; i >= 0; i--) {
            for (int j = 0; j <= i; j++) {
                dp[i][j] += Math.min(
                    dp[i + 1][j],
                    dp[i + 1][j + 1]
                );
            }
        }

        return dp[0][0];
    }
}
```

##  Simple Explanation
Think from the bottom upward!

For each number, look at the two numbers directly below it. Choose the smaller one and add it to the current number.

**Example:**

```text
       2
      3 4
     6 5 7
    4 1 8 3
```

Step 1: Start with the bottom row: `4 1 8 3`

Step 2: Calculate the minimum sums for the row above:
- `6 + min(4, 1) = 7`
- `5 + min(1, 8) = 6`
- `7 + min(8, 3) = 10`

New row: `7 6 10`

Step 3: Move upward:
- `3 + min(7, 6) = 9`
- `4 + min(6, 10) = 10`

New row: `9 10`

Step 4: Calculate the top:
- `2 + min(9, 10) = 11`

**Answer: `11`**

###  Key Idea
Instead of exploring every possible path, calculate the minimum cost from the bottom up and reuse the results.

##  Complexity Analysis
- **Time Complexity:** `O(n²)` — visits every triangle element.
- **Space Complexity:** `O(n²)` — stores the DP table.

**Optimization:** This solution can be optimized to `O(n)` extra space using a one-dimensional DP array.
