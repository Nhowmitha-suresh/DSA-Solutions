# 167. Two Sum II - Input Array Is Sorted

## Problem

Given a **1-indexed** array of integers `numbers` that is sorted in **non-decreasing order**, find two numbers such that they add up to a specific `target`.

Return the indices of the two numbers (1-indexed) as an array `[index1, index2]`.

It is guaranteed that exactly one solution exists, and you may not use the same element twice.

---

## Algorithm (Two Pointer)

1. Initialize two pointers:
   - `left = 0` (start of the array)
   - `right = numbers.length - 1` (end of the array)

2. While `left < right`:
   - Calculate the sum:
     ```
     sum = numbers[left] + numbers[right]
     ```
   - If `sum == target`:
     - Return `{left + 1, right + 1}` because the answer is **1-indexed**.
   - If `sum < target`:
     - Increase `left++` to get a larger sum.
   - Otherwise (`sum > target`):
     - Decrease `right--` to get a smaller sum.

3. Continue until the pair is found.

---

## Why Two Pointers Work?

Since the array is already **sorted**:

- If the current sum is **too small**, moving the left pointer right increases the sum.
- If the current sum is **too large**, moving the right pointer left decreases the sum.
- This allows us to find the answer in a single pass.

---

## Time Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`

---

## Java Code

```java
lass Solution {
    public int[] twoSum(int[] nums, int target) {
        
        int n=nums.length;
        int left=0;
        int right=n-1;

        while(left<right){
            for(int i=0;i<n-1;i++){
                if(nums[left]+nums[right]==target){
                    return new int[]{left+1,right+1};
                }
                else if(nums[left]+nums[right]>target){
                    right--;
                }
                else{
                    left++;
                }
            }
        }
        return new int[]{-1,-1};
    }
}
```
