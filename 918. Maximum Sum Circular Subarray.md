
## LeetCode 918: Maximum Sum Circular Subarray

### Question
Given a circular integer array `nums`, return the maximum possible sum of a non-empty subarray.

A circular array allows the last element to be adjacent to the first element.

### Java Solution
```java
class Solution {
    public int maxSubarraySumCircular(int[] nums) {
        int currentmax = nums[0];
        int maxsum = nums[0];

        int currentmin = nums[0];
        int minsum = nums[0];
        int total = nums[0];
        int circularsum = 0;

        for (int i = 1; i < nums.length; i++) {
            total += nums[i];

            currentmax = Math.max(nums[i], nums[i] + currentmax);
            maxsum = Math.max(maxsum, currentmax);

            currentmin = Math.min(nums[i], nums[i] + currentmin);
            minsum = Math.min(currentmin, minsum);
        }

        if (maxsum < 0) {
            return maxsum;
        }

        circularsum = total - minsum;
        circularsum = Math.max(circularsum, maxsum);

        return circularsum;
    }
}
```

### Approach
1. Use Kadane's algorithm to find the maximum subarray sum (`maxsum`).
2. Find the minimum subarray sum (`minsum`) using a similar approach.
3. Calculate the total sum of the array.
4. The maximum circular sum is `total - minsum`, because removing the minimum subarray leaves the maximum circular subarray.
5. If all elements are negative, return `maxsum` to avoid returning an empty subarray.
6. Return the maximum of `maxsum` and `total - minsum`.

### Complexity
- Time: `O(n)`
- Space: `O(1)`
