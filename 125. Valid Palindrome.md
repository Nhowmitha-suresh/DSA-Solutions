# 125. Valid Palindrome

## Problem

Given a string `s`, return `true` if it is a palindrome after:

- Ignoring non-alphanumeric characters.
- Ignoring letter case.

Otherwise, return `false`.

---

## Approach

- Use two pointers:
  - `left` starts from the beginning.
  - `right` starts from the end.
- Skip characters that are not letters or digits.
- Convert both characters to lowercase and compare.
- If they are different, return `false`.
- Move both pointers inward.
- If all comparisons match, return `true`.

---

## Algorithm

1. Initialize `left = 0` and `right = s.length() - 1`.
2. While `left < right`:
   - Skip non-alphanumeric characters from the left.
   - Skip non-alphanumeric characters from the right.
   - Compare both characters after converting them to lowercase.
   - If they are different, return `false`.
   - Move both pointers.
3. Return `true`.

---

## Java Code

```java
class Solution {
    public boolean isPalindrome(String s) {

        int left = 0;
        int right = s.length() - 1;

        while (left < right) {

            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
                left++;
            }

            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
                right--;
            }

            if (Character.toLowerCase(s.charAt(left)) !=
                Character.toLowerCase(s.charAt(right))) {
                return false;
            }

            left++;
            right--;
        }

        return true;
    }
}
```

# Why Character Class?

`char` only stores a single character.

`Character` is a Java wrapper class that provides useful methods to work with characters.

Instead of manually checking ASCII values, use built-in methods.

Example:

```java
Character.isDigit(ch)
Character.isLetter(ch)
Character.toLowerCase(ch)
```

---

# Character Methods Used

### Character.isLetterOrDigit(ch)

Checks whether the character is:

- Letter (A-Z, a-z)
- Digit (0-9)

Returns:

```java
Character.isLetterOrDigit('A') // true
Character.isLetterOrDigit('8') // true
Character.isLetterOrDigit('@') // false
```

Used to skip spaces and special characters.

---

### Character.toLowerCase(ch)

Converts uppercase letters to lowercase.

Example:

```java
Character.toLowerCase('A') // 'a'
Character.toLowerCase('a') // 'a'
```

Used for case-insensitive comparison.

---

# Why Use Character?

Without `Character`:

```java
(ch >= 'A' && ch <= 'Z') ||
(ch >= 'a' && ch <= 'z') ||
(ch >= '0' && ch <= '9')
```

With `Character`:

```java
Character.isLetterOrDigit(ch)
```

Cleaner, shorter, and easier to read.

---

# When to Use Character Class

Use it whenever a problem involves characters inside a string.

Examples:

- Valid Palindrome
- Valid Anagram
- Reverse Only Letters
- Password Validation
- Count Letters
- Count Digits
- Remove Special Characters
- Camel Case Problems
- String Parsing

---

# How to Recognize It

Use `Character` if the question asks:

- Ignore spaces.
- Ignore punctuation.
- Ignore special characters.
- Ignore case.
- Check uppercase/lowercase.
- Check digits.
- Check letters.

These are strong hints that `Character` methods are useful.

---

# Common Character Methods

| Method | Purpose |
|---------|---------|
| `isLetter(ch)` | Checks alphabet |
| `isDigit(ch)` | Checks digit |
| `isLetterOrDigit(ch)` | Checks letter or digit |
| `isUpperCase(ch)` | Checks uppercase |
| `isLowerCase(ch)` | Checks lowercase |
| `isWhitespace(ch)` | Checks spaces |
| `toLowerCase(ch)` | Converts to lowercase |
| `toUpperCase(ch)` | Converts to uppercase |

---

# Pattern

**Category:** Two Pointers + String

**Recognition:**

- Compare from both ends.
- Ignore some characters.
- Case-insensitive comparison.

Use:

- Two pointers
- `Character.isLetterOrDigit()`
- `Character.toLowerCase()`

---

# Complexity

**Time:** `O(n)`

**Space:** `O(1)`
