
# 49. Group Anagrams

## Question

Given an array of strings `strs`, group the anagrams together.

Return the grouped anagrams in any order.

### Example

```text
Input:
["eat","tea","tan","ate","nat","bat"]

Output:
[
 ["eat","tea","ate"],
 ["tan","nat"],
 ["bat"]
]
```

# Key Observation

All anagrams become the **same string after sorting**.

Example:

```text
eat → aet
tea → aet
ate → aet
```

Since all three become **"aet"**, they belong to the same group.

---

# Intuition

Think of the `HashMap` as a collection of lockers.

```text
Locker Name (Key)          Words (Value)

aet              →     [eat, tea, ate]

ant              →     [tan, nat]

abt              →     [bat]
```

The **sorted word** is the locker name.

The **original words** are stored inside that locker.

---

# Algorithm

### Step 1

Create a HashMap.

- **Key** → Sorted word (`String`)
- **Value** → List of original words (`List<String>`)

```java
HashMap<String, List<String>> map = new HashMap<>();
```

---

### Step 2

Traverse every word.

```java
for(String word : strs)
```

Example

```text
eat
tea
tan
ate
nat
bat
```

---

### Step 3

Convert the word into a character array.

```java
char[] arr = word.toCharArray();
```

Example

```text
eat

↓

['e','a','t']
```

---

### Step 4

Sort the characters.

```java
Arrays.sort(arr);
```

Example

```text
['e','a','t']

↓

['a','e','t']
```

---

### Step 5

Convert the sorted array back into a String.

```java
String key = new String(arr);
```

Example

```text
eat

↓

aet
```

The sorted string becomes the **key**.

---

### Step 6

Check whether the key already exists.

```java
if (!map.containsKey(key)) {
    map.put(key, new ArrayList<>());
}
```

If the key is not present,

create a new list.

Example

```text
Before

{}

↓

After

{
aet → []
}
```

---

### Step 7

Add the original word to the corresponding list.

```java
map.get(key).add(word);
```

Think of it like this:

```text
Current Word

tea

↓

Sorted

aet

↓

map.get("aet")

↓

[eat]

↓

.add("tea")

↓

[eat, tea]
```

> **Remember**
>
> `map.get(key)` returns the **list**, not the key.

---

### Step 8

Return all grouped lists.

```java
return new ArrayList<>(map.values());
```

Current Map

```text
{
aet → [eat, tea, ate]

ant → [tan, nat]

abt → [bat]
}
```

Return

```text
[
[eat, tea, ate],

[tan, nat],

[bat]
]
```

# Why HashMap?

Without a HashMap

```text
New word

↓

Sort it

↓

Search every group

↓

Find correct group

↓

Add word
```

Time is wasted searching.

---

With a HashMap

```text
New word

↓

Sort it

↓

Get the key

↓

Jump directly to that group

↓

Add word
```

No searching is needed.

---

# Code

```java
import java.util.*;

class Solution {

    public List<List<String>> groupAnagrams(String[] strs) {

        HashMap<String, List<String>> map = new HashMap<>();

        for (String word : strs) {

            // Convert to character array
            char[] arr = word.toCharArray();

            // Sort characters
            Arrays.sort(arr);

            // Sorted string becomes the key
            String key = new String(arr);

            // Create new group if key is not present
            if (!map.containsKey(key)) {
                map.put(key, new ArrayList<>());
            }

            // Add original word to its group
            map.get(key).add(word);
        }

        // Return all grouped anagrams
        return new ArrayList<>(map.values());
    }
}
```

# Time Complexity

Let

- `n` = number of words
- `k` = average length of a word

Sorting each word takes

```text
O(k log k)
```

Total

```text
O(n × k log k)
```

---

# Space Complexity

```text
O(n × k)
```

Used for storing all the groups.
