## LeetCode 112: Path Sum

### Question
Given the root of a binary tree and an integer `targetSum`, return `true` if there is a root-to-leaf path whose node values add up to `targetSum`. Otherwise, return `false`.

### Algorithm
1. Start from the root node.
2. If the current node is `null`, return `false` because no path exists.
3. Check whether the current node is a leaf (both left and right children are `null`).
4. If it is a leaf, check whether `targetSum == root.val`. If equal, return `true`; otherwise, return `false`.
5. If it is not a leaf, subtract the current node's value from `targetSum`.
6. Recursively check the left subtree using the updated target sum.
7. Recursively check the right subtree using the updated target sum.
8. If either the left or right subtree returns `true`, return `true`.
9. If neither subtree contains a valid path, return `false`.

### Java Solution
```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) {
            return false;
        }

        if (root.left == null && root.right == null) {
            return targetSum == root.val;
        }

        int remaining = targetSum - root.val;

        return hasPathSum(root.left, remaining) ||
               hasPathSum(root.right, remaining);
    }
}
