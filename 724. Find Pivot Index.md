# Find Pivot Index

## Question

Given an integer array `nums`, find the **pivot index** of the array.

The pivot index is the index where the sum of all elements **strictly to the left** of the index is equal to the sum of all elements **strictly to the right**.

### Rules

- If the pivot index is `0`, the left sum is considered `0`.
- If the pivot index is the last index, the right sum is considered `0`.
- If there are multiple pivot indices, return the **leftmost pivot index**.
- If no pivot index exists, return `-1`.

### Example 1

**Input:**

    nums = [1, 7, 3, 6, 5, 6]

**Output:**

    3

### Explanation

For index `3`:

    Left elements  = [1, 7, 3]
    Right elements = [5, 6]

    Left Sum  = 1 + 7 + 3 = 11
    Right Sum = 5 + 6 = 11

Since both sums are equal, index `3` is the pivot index.

### Example 2

**Input:**

    nums = [1, 2, 3]

**Output:**

    -1

There is no index where the left sum and right sum are equal.

---

## Algorithm

The direct approach would calculate the left sum and right sum separately for every index. However, this would take `O(n²)` time.

We can solve the problem in `O(n)` time using the **total sum and a running left sum**.

### Step 1: Calculate Total Sum

First, calculate the sum of all elements in the array.

    totalSum = sum of all elements

For example:

    nums = [1, 7, 3, 6, 5, 6]

    totalSum = 1 + 7 + 3 + 6 + 5 + 6
             = 28

### Step 2: Initialize Left Sum

Start with:

    leftSum = 0

Initially, there are no elements to the left of index `0`.

### Step 3: Calculate Right Sum

For every index `i`, we already know:

    totalSum = leftSum + nums[i] + rightSum

Therefore:

    rightSum = totalSum - leftSum - nums[i]

This allows us to calculate the right sum in `O(1)` time.

### Step 4: Check the Pivot Condition

If:

    leftSum == rightSum

then the current index `i` is the pivot index.

Return `i`.

### Step 5: Update Left Sum

If the current index is not a pivot, add the current element to `leftSum` before moving to the next index.

    leftSum = leftSum + nums[i]

### Step 6: Return -1

If the entire array is checked and no pivot index is found, return:

    -1

### Dry Run

For:

    nums = [1, 7, 3, 6, 5, 6]

Total sum:

    totalSum = 28

| Index | Current | Left Sum | Right Sum | Result |
|------:|--------:|---------:|----------:|--------|
| 0 | 1 | 0 | 27 | Not Pivot |
| 1 | 7 | 1 | 20 | Not Pivot |
| 2 | 3 | 8 | 17 | Not Pivot |
| 3 | 6 | 11 | 11 | Pivot |

At index `3`:

    leftSum  = 11
    rightSum = 11

Therefore:

    Answer = 3
## Java Code

```java
class Solution {
    public int pivotIndex(int[] nums) {

        int totalSum = 0;

        for (int num : nums) {
            totalSum += num;
        }

        int leftSum = 0;

        for (int i = 0; i < nums.length; i++) {

            int rightSum = totalSum - leftSum - nums[i];

            if (leftSum == rightSum) {
                return i;
            }

            leftSum += nums[i];
        }

        return -1;
    }
}
