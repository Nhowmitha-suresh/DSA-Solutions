
# 1207. Unique Number of Occurrences

**Difficulty:** Easy  
**Topics:** Array, Hash Map, Hash Set

## Problem Statement

Given an array of integers `arr`, return `true` if the number of occurrences of each value in the array is unique. Otherwise, return `false`.

### Example 1

**Input:**
```text
arr = [1, 2, 2, 1, 1, 3]
```

**Output:**
```text
true
```

**Explanation:**

- `1` occurs 3 times.
- `2` occurs 2 times.
- `3` occurs 1 time.

All frequencies are unique: `3, 2, 1`.

### Example 2

**Input:**
```text
arr = [1, 2]
```

**Output:**
```text
false
```

**Explanation:**

- `1` occurs 1 time.
- `2` occurs 1 time.

Both values have the same frequency.

### Example 3

**Input:**
```text
arr = [-3, 0, 1, -3, 1, 1, 1, -3, 10, 0]
```

**Output:**
```text
true
```

## Algorithm

1. Create a `HashMap` to store each number and its frequency.
2. Traverse the array and count the occurrences of each number.
3. Create a `HashSet` to store the frequencies.
4. Traverse the frequency values:
   - If a frequency already exists in the set, return `false`.
   - Otherwise, add the frequency to the set.
5. If all frequencies are unique, return `true`.

## Java Solution

```java

import java.util.*;

class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        HashMap<Integer, Integer> freq = new HashMap<>();

        // Count each number
        for (int num : arr) {
            freq.put(num, freq.getOrDefault(num, 0) + 1);
        }

        HashSet<Integer> seen = new HashSet<>();

        // Check whether frequencies repeat
        for (int count : freq.values()) {
            if (seen.contains(count)) {
                return false;
            }

            seen.add(count);
        }

        return true;
    }
}

```

## Complexity Analysis

- **Time Complexity:** `O(n)` — Counting and checking frequencies take linear time on average.
- **Space Complexity:** `O(n)` — The HashMap and HashSet store up to `n` entries.

## Key Takeaway

- `HashMap` counts how many times each number appears.
- `HashSet` checks whether two numbers have the same frequency.
- `seen.add(count)` returns `false` if that frequency already exists.
