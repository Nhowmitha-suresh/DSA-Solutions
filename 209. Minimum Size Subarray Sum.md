# 🚀 LeetCode 209 - Minimum Size Subarray Sum

**Difficulty:** Medium  
**Topics:** Array, Sliding Window, Two Pointers

---

# 📝 Question

Given an array of **positive integers** `nums` and a positive integer `target`, return the **minimum length** of a subarray whose sum is **greater than or equal to** `target`.

If there is no such subarray, return **0** instead.

### Constraints

- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

---

# 💡 Algorithm (Sliding Window)

1. Initialize:
   - `left = 0`
   - `sum = 0`
   - `minLength = Integer.MAX_VALUE`

2. Traverse the array using the `right` pointer.

3. Add the current element to `sum`.

4. While `sum >= target`:
   - Update `minLength` with the current window size (`right - left + 1`).
   - Remove `nums[left]` from `sum`.
   - Increment `left` to shrink the window.

5. Continue until the end of the array.

6. If `minLength` is never updated, return `0`; otherwise, return `minLength`.

---

# ✅ Java Code

```java
class Solution {

    public int minSubArrayLen(int target, int[] nums) {

        int left = 0;
        int sum = 0;
        int minLength = Integer.MAX_VALUE;

        for (int right = 0; right < nums.length; right++) {

            // Expand the window
            sum += nums[right];

            // Shrink the window while the sum is sufficient
            while (sum >= target) {

                minLength = Math.min(minLength, right - left + 1);

                sum -= nums[left];
                left++;
            }
        }

        return minLength == Integer.MAX_VALUE ? 0 : minLength;
    }
}
```

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`
