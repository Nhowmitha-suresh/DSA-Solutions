
# LeetCode 438 - Find All Anagrams in a String

## Question
Given two strings `s` and `p`, find all starting indices of substrings in `s` that are anagrams of `p`.

**Example:**
- Input: `s = "cbaebabacd", p = "abc"`
- Output: `[0, 6]`

## Algorithm
1. Create two arrays to count characters.
2. Count characters in `p` and the first window of `s`.
3. Compare both arrays. If equal, store index `0`.
4. Slide the window by adding the next character and removing the previous character.
5. If both arrays match, store the starting index.
6. Return the result.

## Java Code

```java
import java.util.*;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();

        if (p.length() > s.length()) return result;

        int[] pCount = new int[26];
        int[] window = new int[26];

        for (int i = 0; i < p.length(); i++) {
            pCount[p.charAt(i) - 'a']++;
            window[s.charAt(i) - 'a']++;
        }

        if (Arrays.equals(pCount, window))
            result.add(0);

        for (int i = p.length(); i < s.length(); i++) {
            window[s.charAt(i) - 'a']++;
            window[s.charAt(i - p.length()) - 'a']--;

            if (Arrays.equals(pCount, window))
                result.add(i - p.length() + 1);
        }

        return result;
    }
}
```

## Line-by-Line Explanation
- `result`: Stores the starting indices of anagrams.
- `p.length() > s.length()`: If `p` is longer, return an empty list.
- `pCount[]`: Counts characters in `p`.
- `window[]`: Counts characters in the current window of `s`.
- `charAt(i) - 'a'`: Converts a lowercase letter into an array index from `0` to `25`.
- `++`: Adds the character to its frequency count.
- `Arrays.equals()`: Checks whether both frequency arrays are equal.
- `--`: Removes the outgoing character from the window.
- `i - p.length() + 1`: Calculates the starting index of the current window.
- `return result`: Returns all matching indices.

## Complexity
- Time: `O(n)`
- Space: `O(1)`
