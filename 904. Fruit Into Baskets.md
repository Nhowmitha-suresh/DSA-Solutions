# LeetCode 904 - Fruit Into Baskets

## Question
You are given an array `fruits` where `fruits[i]` represents the type of fruit at position `i`.

You have two baskets, and each basket can contain only one type of fruit. Find the maximum number of fruits you can collect from a contiguous section of the array.

## Example
Input: `fruits = [1,2,1,2,3]`

Output: `4`

Explanation: The longest valid window is `[1,2,1,2]`, which contains only 2 different fruit types.

## Algorithm
1. Use the **Sliding Window** technique with two pointers: `left` and `right`.
2. Use a `HashMap` to store the frequency of each fruit inside the current window.
3. Move `right` forward and add `fruits[right]` to the map.
4. If the map contains more than `2` different fruit types, the window becomes invalid.
5. Start the shrinking phase by moving `left` forward.
6. Decrease the frequency of `fruits[left]`.
7. If its frequency becomes `0`, remove that fruit type from the map.
8. Continue shrinking until the map contains at most `2` fruit types.
9. Calculate the current window size using `right - left + 1`.
10. Store the maximum window size in `ans`.

## Key Idea
`HashMap` → keeps track of fruit frequencies.

`Sliding Window` → maintains the longest contiguous section containing at most 2 distinct fruit types.

## Java Program
```java class Solution {
    public int totalFruit(int[] fruits) {

        int left = 0;
        int ans = 0;

        HashMap<Integer, Integer> map = new HashMap<>();

        for (int right = 0; right < fruits.length; right++) {

            // Add the current fruit
            map.put(fruits[right],
                    map.getOrDefault(fruits[right], 0) + 1);

            // Shrink window if there are more than 2 types
            while (map.size() > 2) {

                map.put(fruits[left],
                        map.get(fruits[left]) - 1);

                if (map.get(fruits[left]) == 0) {
                    map.remove(fruits[left]);
                }

                left++;
            }

            // Update maximum window length
            ans = Math.max(ans, right - left + 1);
        }

        return ans;
    }
}
```
## Complexity
Time: `O(n)`

Space: `O(1)` because the HashMap stores at most 3 fruit types during processing.
