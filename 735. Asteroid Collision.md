# LeetCode 735 - Asteroid Collision

## Question

Given an array of asteroids, each asteroid moves in a direction.

- Positive value → moves right
- Negative value → moves left
- When two asteroids collide, the smaller one is destroyed.
- If both have the same size, both are destroyed.
- Asteroids moving in the same direction never collide.

Return the state of the asteroids after all collisions.

### Example

**Input:**
```text
[5, 10, -5]
```

**Output:**
```text
[5, 10]
```

---

## Algorithm

1. Create a stack to store the remaining asteroids.
2. Traverse each asteroid.
3. A collision is possible only when:
   ```text
   stack top > 0
   current asteroid < 0
   ```
4. Compare the two asteroids:
   - If stack top is smaller → remove it using `pop()`.
   - If both are equal → remove stack top and destroy current asteroid.
   - If stack top is bigger → destroy current asteroid.
5. If the current asteroid is not destroyed, push it into the stack.
6. Convert the stack into an array and return it.

---

## Code

```java
import java.util.*;

class Solution {
    public int[] asteroidCollision(int[] asteroids) {

        Stack<Integer> stack = new Stack<>();

        for (int asteroid : asteroids) {

            boolean destroyed = false;

            while (!stack.isEmpty()
                    && stack.peek() > 0
                    && asteroid < 0) {

                if (stack.peek() < -asteroid) {
                    // Stack asteroid is smaller
                    stack.pop();
                }

                else if (stack.peek() == -asteroid) {
                    // Both are destroyed
                    stack.pop();
                    destroyed = true;
                    break;
                }

                else {
                    // Current asteroid is smaller
                    destroyed = true;
                    break;
                }
            }

            if (!destroyed) {
                stack.push(asteroid);
            }
        }

        int[] result = new int[stack.size()];

        for (int i = 0; i < stack.size(); i++) {
            result[i] = stack.get(i);
        }

        return result;
    }
}
```

---

## Important Condition

```java
stack.peek() > 0 && asteroid < 0
```

This means:

```text
Stack asteroid  → 
Current asteroid ←

They are moving towards each other.
```

Only this combination can cause a collision.

---

## Stack Functions

```java
stack.push(x);   // Add element
stack.pop();     // Remove top element
stack.peek();    // View top element
stack.isEmpty(); // Check if stack is empty
```

---

## Example

```text
Input: [5, 10, -5]

5   → [5]
10  → [5, 10]

-5 comes:

10 →   ← -5

10 > 5
Therefore -5 is destroyed.

Final: [5, 10]
```

- **Time:** `O(n)`
- **Space:** `O(n)`

## Key Takeaway

```text
Positive → moves right
Negative → moves left

Collision:
Positive + Negative

Smaller → destroyed
Equal   → both destroyed
Bigger  → survives
```
