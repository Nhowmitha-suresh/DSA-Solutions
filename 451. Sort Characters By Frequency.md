
## 451. Sort Characters By Frequency (Medium)

### Problem
Given a string `s`, sort its characters in decreasing order of frequency. Characters with equal frequencies can appear in any order.

**Example**
- Input: `s = "tree"`
- Output: `"eert"`

### Algorithm
1. Count each character using a `HashMap`.
2. Store distinct characters in a list.
3. Sort characters by frequency in descending order.
4. Append each character according to its frequency using `StringBuilder`.
5. Return the result.

### Java Code
```java
import java.util.*;

class Solution {
    public String frequencySort(String s) {
        HashMap<Character, Integer> map = new HashMap<>();

        for (char c : s.toCharArray()) {
            map.put(c, map.getOrDefault(c, 0) + 1);
        }

        List<Character> list = new ArrayList<>(map.keySet());
        list.sort((a, b) -> map.get(b) - map.get(a));

        StringBuilder ans = new StringBuilder();

        for (char c : list) {
            for (int i = 0; i < map.get(c); i++) {
                ans.append(c);
            }
        }

        return ans.toString();
    }
}
```

### Complexity Analysis
- **Time Complexity:** `O(n + k log k)`
- **Space Complexity:** `O(n + k)`

Here, `n` is the string length and `k` is the number of distinct characters.

### Key Concepts
`HashMap` | Frequency Counting | Custom Sorting | `StringBuilder`
