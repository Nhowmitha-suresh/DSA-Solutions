
# 191. Number of 1 Bits

- **Difficulty:** Easy
- **Topics:** Bit Manipulation
- **Language:** Java

## Problem

Given a positive integer `n`, return the number of set bits (`1`s) in its binary representation, also known as its **Hamming Weight**.

## Examples

### Example 1

**Input:**
```text
n = 11
```

**Output:**
```text
3
```

**Explanation:**

The binary representation of `11` is `1011`, which contains three set bits.

### Example 2

**Input:**
```text
n = 128
```

**Output:**
```text
1
```

**Explanation:**

The binary representation of `128` is `10000000`, which contains one set bit.

### Example 3

**Input:**
```text
n = 2147483645
```

**Output:**
```text
30
```

**Explanation:**

The binary representation contains thirty set bits.

## Algorithm

1. Initialize `count = 0`.
2. Repeat while `n != 0`:
   - Remove the rightmost set bit using `n = n & (n - 1)`.
   - Increment `count`.
3. Return `count`.

Each iteration removes exactly one set bit.

## Java Code — Optimal Approach

```java
class Solution {
    public int hammingWeight(int n) {
        int count = 0;

        while (n != 0) {
            n = n & (n - 1);
            count++;
        }

        return count;
    }
}
```

## Dry Run

**Input:** `n = 11`

Binary representation: `1011`

| Iteration | n before | n - 1 (binary) | `n & (n - 1)` | count |
|---:|:---:|:---:|:---:|---:|
| 1 | `1011` | `1010` | `1010` | 1 |
| 2 | `1010` | `1001` | `1000` | 2 |
| 3 | `1000` | `0111` | `0000` | 3 |

The loop stops when `n` becomes `0`.

**Output:** `3`

## How Does `n & (n - 1)` Work?

The expression removes the rightmost `1` bit.

Example: `n = 11`

```text
n       = 1011
n - 1   = 1010
          ----
AND     = 1010
```

One set bit is removed. Repeating this operation until `n` becomes zero gives the total number of set bits.

## Alternative Approach — Right Shift

```java
class Solution {
    public int hammingWeight(int n) {
        int count = 0;

        while (n != 0) {
            count += (n & 1);
            n = n >>> 1;
        }

        return count;
    }
}
```

Here:
- `n & 1` checks the rightmost bit.
- `n >>> 1` shifts the bits one position to the right.
- `count` increases when the rightmost bit is `1`.

## Complexity Analysis

- **Time Complexity:** `O(k)` for the set-bit removal approach, where `k` is the number of set bits. In the worst case, this is `O(32)` for a Java `int`.
- **Space Complexity:** `O(1)` — Only a constant amount of extra memory is used.

## Key Takeaways

- A set bit is a binary digit equal to `1`.
- `n & (n - 1)` removes the rightmost set bit.
- Brian Kernighan's algorithm counts set bits efficiently.
- The right-shift method checks each bit individually.
