# 680. Valid Palindrome II

## Problem

Given a string `s`, return `true` if it can become a palindrome after deleting **at most one character**. Otherwise, return `false`.

---

## Examples

### Example 1

```text
Input : "aba"
Output: true
```

Already a palindrome.

---

### Example 2

```text
Input : "abca"
Output: true
```

Delete `'c'` → `"aba"`

or

Delete `'b'` → `"aca"`

---

### Example 3

```text
Input : "abc"
Output: false
```

Deleting one character still cannot make it a palindrome.

---

# Pattern

- Two Pointers
- String
- Greedy Decision

---

# Intuition

This is almost the same as **LC 125 (Valid Palindrome)**.

The only difference is:

> You are allowed to delete **one** character.

When characters are equal, continue normally.

When the **first mismatch** occurs, there are only **two possible choices**:

- Skip the left character.
- Skip the right character.

If either remaining substring is a palindrome, the answer is `true`.

---

# Algorithm

1. Initialize two pointers.
   - `left = 0`
   - `right = n - 1`

2. Compare characters.

3. If characters are equal:
   - Move both pointers.

4. If characters are different:
   - Skip the left character and check.
   - Skip the right character and check.
   - If either is a palindrome, return `true`.

5. If the loop finishes without problems, return `true`.

---

# Why Two Functions?

This problem has **two different responsibilities**.

Instead of mixing both into one method, we separate them.

---

## Function 1 : `validPalindrome()`

### Purpose

This is the **main function**.

Its job is to:

- Traverse the string.
- Find the first mismatch.
- Decide which character to remove.

It **does not** check the remaining substring completely.

Instead, it asks another function.

---

### Responsibilities

- Initialize two pointers.
- Compare characters.
- Detect the first mismatch.
- Try:
  - Skip left
  - Skip right
- Return the final answer.

---

### Flow

```text
Compare

↓

Characters equal?

↓

Yes

↓

Move pointers

↓

No

↓

Skip Left
      OR
Skip Right

↓

Ask helper function
```

---

## Function 2 : `isPalindrome()`

### Purpose

This is the **helper function**.

Its job is very simple.

It only answers one question:

> Is this substring a palindrome?

It does **not** know anything about deleting characters.

It simply performs a normal palindrome check.

Exactly the same logic as **LC 125**.

---

### Responsibilities

- Compare characters.
- Move pointers.
- Return `false` if any mismatch occurs.
- Return `true` if all characters match.

---

# Why Do We Need a Helper Function?

Suppose the first mismatch is:

```text
abca

b != c
```

Now we need to check:

```text
Skip b

↓

aca
```

and

```text
Skip c

↓

aba
```

Both of these are just **normal palindrome checks**.

Instead of writing the same palindrome logic twice,

we simply write it once inside

```java
isPalindrome()
```

and reuse it.

This keeps the code:

- Clean
- Short
- Easy to debug
- Easy to reuse

# Code

```java
class Solution {

    public boolean validPalindrome(String s) {

        int left = 0;
        int right = s.length() - 1;

        while (left < right) {

            if (s.charAt(left) != s.charAt(right)) {

                return isPalindrome(s, left + 1, right) ||
                       isPalindrome(s, left, right - 1);
            }

            left++;
            right--;
        }

        return true;
    }

    private boolean isPalindrome(String s, int left, int right) {

        while (left < right) {

            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }

            left++;
            right--;
        }

        return true;
    }
}
```

# Recognition Tips

Use this approach when the question contains words like:

- Delete at most one character
- Remove one element
- Skip one mismatch
- Almost palindrome

Immediately think:

```text

Try both possibilities
