# 647. Palindromic Substrings

## Question

Given a string `s`, return the number of palindromic substrings in it.

A string is a palindrome when it reads the same backward as forward.

A substring is a contiguous sequence of characters within a string.

### Example 1

Input:
`s = "abc"`

Output:
`3`

### Example 2

Input:
`s = "aaa"`

Output:
`6`

## Algorithm

1. Iterate through every index `i` as a possible center.
2. Call `expand(s, i, i)` to count odd-length palindromes.
3. Call `expand(s, i, i + 1)` to count even-length palindromes.
4. In `expand()`, compare the characters at `left` and `right`.
5. If they are equal, increment `count` and expand outward.
6. Return the total count.

## Code

```java
class Solution {

    public int countSubstrings(String s) {

        int count = 0;

        for (int i = 0; i < s.length(); i++) {

            count += expand(s, i, i);

            count += expand(s, i, i + 1);
        }

        return count;
    }

    private int expand(String s, int left, int right) {

        int count = 0;

        while (left >= 0 &&
               right < s.length() &&
               s.charAt(left) == s.charAt(right)) {

            count++;

            left--;
            right++;
        }

        return count;
    }
}
