# Longest Valid Parentheses

## Problem

Given a string `s` containing only `'('` and `')'`, find the length of the longest valid parentheses substring.

A valid parentheses substring is a substring where:

- Every opening parenthesis `(` has a matching closing parenthesis `)`.
- Parentheses are correctly nested.

### Example

**Input:**

`s = "(()"`

**Output:**

`2`

**Explanation:**

The longest valid substring is:

`"()"`

---

**Input:**

`s = ")()())"`

**Output:**

`4`

**Explanation:**

The longest valid substring is:

`"()()"`

---

## Simple Algorithm

1. Create a `Stack<Integer>` to store indices.
2. Push `-1` into the stack initially.
3. Traverse the string from left to right.
4. If the current character is `'('`, push its index into the stack.
5. If the current character is `')'`:
   - Pop the top index from the stack.
   - If the stack becomes empty, push the current index as the new starting point.
   - Otherwise, calculate the length using:
     `i - stack.peek()`
6. Update `max` with the maximum valid length.
7. Return `max`.

### Approach

`Stack of Indices → Match Parentheses → Calculate Length → Track Maximum`

---

## Code

```java    class Solution {
        public int longestValidParentheses(String s) {

            Stack<Integer> stack = new Stack<>();
            stack.push(-1);

            int max = 0;

            for (int i = 0; i < s.length(); i++) {

                if (s.charAt(i) == '(') {
                    stack.push(i);
                }
                else {
                    stack.pop();

                    if (stack.isEmpty()) {
                        stack.push(i);
                    }
                    else {
                        max = Math.max(max, i - stack.peek());
                    }
                }
            }

            return max;
        }
    }
```
