# Merge k Sorted Lists

## Problem

You are given an array of `k` linked lists.

Each linked list is sorted in ascending order.

Your task is to merge all the linked lists into one sorted linked list and return the head of the merged list.

### Example

**Input:**
`lists = [[1,4,5],[1,3,4],[2,6]]`

**Output:**
`[1,1,2,3,4,4,5,6]`

---

## Simple Algorithm

1. Create an `ArrayList<Integer>` to store all node values.
2. Traverse every linked list.
3. Add each node value to the `ArrayList`.
4. Sort the `ArrayList`.
5. Create a new linked list using the sorted values.
6. Return the new linked list.

### Approach

`Linked Lists → Collect Values → Sort → Create New Linked List`

---

## Code

   ```java  class Solution {
        public ListNode mergeKLists(ListNode[] lists) {
            ArrayList<Integer> values = new ArrayList<>();

            for (ListNode list : lists) {
                while (list != null) {
                    values.add(list.val);
                    list = list.next;
                }
            }

            Collections.sort(values);

            ListNode dummy = new ListNode(0);
            ListNode current = dummy;

            for (int value : values) {
                current.next = new ListNode(value);
                current = current.next;
            }

            return dummy.next;
        }
    }
```

## Dry Run

Given:

`lists = [[1,4,5],[1,3,4],[2,6]]`

### Collect Values

First list:

`1 → 4 → 5`

Second list:

`1 → 3 → 4`

Third list:

`2 → 6`

All values:

`[1,4,5,1,3,4,2,6]`

### Sort

Before sorting:

`[1,4,5,1,3,4,2,6]`

After sorting:

`[1,1,2,3,4,4,5,6]`

### Build Result

`1 → 1 → 2 → 3 → 4 → 4 → 5 → 6`

---

## Complexity Analysis

Let `N` be the total number of nodes across all linked lists.

### Time Complexity

Collecting all values:

`O(N)`

Sorting:

`O(N log N)`

Creating the result linked list:

`O(N)`

Therefore:

`O(N log N)`

### Space Complexity

The `ArrayList` stores all `N` values:

`O(N)`

The new linked list contains `N` nodes:

`O(N)`

Therefore:

`O(N)`

---

## Key Idea

The solution follows:

`Collect → Sort → Rebuild`

## Final Complexity

- **Time:** `O(N log N)`
- **Space:** `O(N)`
