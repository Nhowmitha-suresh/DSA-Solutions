# LeetCode 75 - Sort Colors

## Problem Statement

Given an array `nums` with `n` objects colored red, white, or blue, sort them **in-place** so that objects of the same color are adjacent.

The colors are represented by:
- `0` → Red
- `1` → White
- `2` → Blue

You must solve this problem **without using the library sort function**.

### Example

**Input**
```text
nums = [2,0,2,1,1,0]
```

**Output**
```text
[0,0,1,1,2,2]
```

---

# Algorithm (Dutch National Flag Algorithm)

1. Initialize three pointers:
   - `start` → position for next `0`
   - `mid` → current element
   - `end` → position for next `2`

2. Traverse while `mid <= end`.

3. If `nums[mid] == 0`
   - Swap `nums[start]` and `nums[mid]`
   - Increment `start` and `mid`

4. If `nums[mid] == 1`
   - Increment `mid`

5. If `nums[mid] == 2`
   - Swap `nums[mid]` and `nums[end]`
   - Decrement `end`
   - Do **not** increment `mid`

---

# Java Code

```java
class Solution {
    public void sortColors(int[] nums) {

        int start = 0;
        int mid = 0;
        int end = nums.length - 1;

        while (mid <= end) {

            if (nums[mid] == 0) {
                swap(nums, start, mid);
                start++;
                mid++;
            }
            else if (nums[mid] == 1) {
                mid++;
            }
            else {
                swap(nums, mid, end);
                end--;
            }
        }
    }

    public void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

---

# Complexity Analysis

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

---

# Key Points to Remember

- `0` → Move to **start** (`start++`, `mid++`)
- `1` → Already in correct position (`mid++`)
- `2` → Move to **end** (`end--` only)

> **Important:** After swapping with `end`, **do not increment `mid`**, because the new element at `mid` still needs to be checked.
