# Candy

## Problem

There are `n` children standing in a line.

Each child has a rating represented by the integer array `ratings`.

You need to distribute candies to the children following these rules:

1. Each child must have at least one candy.
2. A child with a higher rating than an immediate neighbor must receive more candies than that neighbor.

Return the minimum number of candies required.

### Example

**Input:**

`ratings = [1,0,2]`

**Output:**

`5`

**Distribution:**

`[2,1,2]`

Another example:

**Input:**

`ratings = [1,2,2]`

**Output:**

`4`

**Distribution:**

`[1,2,1]`

---

## Simple Algorithm

1. Create an array `candies` of the same size as `ratings`.
2. Give every child `1` candy initially.
3. Traverse from left to right:
   - If the current child's rating is greater than the previous child's rating, give the current child one more candy than the previous child.
4. Traverse from right to left:
   - If the current child's rating is greater than the next child's rating, make sure the current child has at least one more candy than the next child.
5. Add all candy values.
6. Return the total.

### Approach

`Initialize → Left to Right → Right to Left → Calculate Sum`

---

## Code

  ```java  class Solution {
        public int candy(int[] ratings) {
            int n = ratings.length;
            int[] candies = new int[n];

            for (int i = 0; i < n; i++) {
                candies[i] = 1;
            }

            for (int i = 1; i < n; i++) {
                if (ratings[i] > ratings[i - 1]) {
                    candies[i] = candies[i - 1] + 1;
                }
            }

            for (int i = n - 2; i >= 0; i--) {
                if (ratings[i] > ratings[i + 1]) {
                    candies[i] = Math.max(candies[i], candies[i + 1] + 1);
                }
            }

            int result = 0;

            for (int candy : candies) {
                result += candy;
            }

            return result;
        }
    }
```

## Dry Run

Given:

`ratings = [1,0,2]`

### Step 1: Initialize

Every child gets at least one candy.

`candies = [1,1,1]`

### Step 2: Left to Right

Compare each child with the previous child.

`ratings[1] = 0` is not greater than `ratings[0] = 1`.

So:

`candies = [1,1,1]`

Next:

`ratings[2] = 2` is greater than `ratings[1] = 0`.

Therefore:

`candies[2] = candies[1] + 1`

So:

`candies = [1,1,2]`

### Step 3: Right to Left

Now compare each child with the next child.

`ratings[1] = 0` is not greater than `ratings[2] = 2`.

No change:

`candies = [1,1,2]`

Next:

`ratings[0] = 1` is greater than `ratings[1] = 0`.

Therefore:

`candies[0] = Math.max(candies[0], candies[1] + 1)`

`candies[0] = Math.max(1,2)`

So:

`candies = [2,1,2]`

### Step 4: Calculate Total

`2 + 1 + 2 = 5`

Therefore:

`result = 5`

---

## Why Two Traversals?

The first traversal handles the condition:

`ratings[i] > ratings[i-1]`

This makes sure the current child has more candies than the child on the left.

The second traversal handles:

`ratings[i] > ratings[i+1]`

This makes sure the current child has more candies than the child on the right.

Using both directions ensures that both neighboring conditions are satisfied.

---

## Important Part

The key line in the second traversal is:

    candies[i] = Math.max(candies[i], candies[i + 1] + 1);

We use `Math.max()` because the current child may already have received more candies during the left-to-right traversal.

For example:

`ratings = [1,2,3,2,1]`

After the left-to-right traversal:

`candies = [1,2,3,1,1]`

During the right-to-left traversal, the decreasing sequence needs to be fixed.

The final result becomes:

`candies = [1,2,3,2,1]`

We must keep the larger value whenever a child has already received enough candies from the other direction.

---

## Complexity Analysis

Let `n` be the number of children.

### Time Complexity

First initialization:

`O(n)`

Left-to-right traversal:

`O(n)`

Right-to-left traversal:

`O(n)`

Final sum:

`O(n)`

Therefore:

`O(n)`

### Space Complexity

The `candies` array contains `n` elements:

`O(n)`

Therefore:

`O(n)`

---

## Key Idea

The solution follows:

`Give 1 → Check Left → Check Right → Sum`

The two passes handle both sides of every child while `Math.max()` preserves the larger candy requirement.

## Final Complexity

- **Time:** `O(n)`
- **Space:** `O(n)`
