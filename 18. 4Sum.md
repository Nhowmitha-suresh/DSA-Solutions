# Algorithm

1. Sort the array.
2. Iterate through the array using index `i` to fix the first element.
3. Skip duplicate values for `i`.
4. Iterate using index `j` to fix the second element.
5. Skip duplicate values for `j`.
6. Initialize two pointers:
   - `left = j + 1`
   - `right = n - 1`
7. While `left < right`:
   - Calculate the sum of `nums[i] + nums[j] + nums[left] + nums[right]`.
   - If the sum equals the target:
     - Add the quadruplet to the answer.
     - Move both pointers (`left++`, `right--`).
     - Skip duplicate values for `left` and `right`.
   - If the sum is smaller than the target:
     - Move `left` to the right (`left++`).
   - If the sum is greater than the target:
     - Move `right` to the left (`right--`).
8. Continue until all possible quadruplets are explored.
9. Return the list of unique quadruplets.

# Java Code

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {

        Arrays.sort(nums);

        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n - 3; i++) {

            // Skip duplicate first elements
            if (i > 0 && nums[i] == nums[i - 1])
                continue;

            for (int j = i + 1; j < n - 2; j++) {

                // Skip duplicate second elements
                if (j > i + 1 && nums[j] == nums[j - 1])
                    continue;

                int left = j + 1;
                int right = n - 1;

                while (left < right) {

                    long sum = (long) nums[i] + nums[j] + nums[left] + nums[right];

                    if (sum == target) {

                        ans.add(Arrays.asList(
                                nums[i],
                                nums[j],
                                nums[left],
                                nums[right]
                        ));

                        left++;
                        right--;

                        // Skip duplicate left values
                        while (left < right && nums[left] == nums[left - 1])
                            left++;

                        // Skip duplicate right values
                        while (left < right && nums[right] == nums[right + 1])
                            right--;
```

### Time Complexity
- **Sorting:** `O(n log n)`
- **Nested loops + Two Pointers:** `O(n³)`
- **Overall:** **O(n³)**

### Space Complexity
- **O(1)** (excluding the output list)
