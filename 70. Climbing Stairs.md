
# Climbing Stairs — LeetCode 70

## Java Solution
```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;

        int first = 1;
        int second = 2;

        for (int i = 3; i <= n; i++) {
            int current = first + second;
            first = second;
            second = current;
        }

        return second;
    }
}
```

## Algorithm
1. If `n <= 2`, return `n`.
2. Initialize `first = 1` and `second = 2`.
3. Loop from `i = 3` to `n`.
4. Calculate `current = first + second`.
5. Update `first = second` and `second = current`.
6. Return `second`.

## Shortcut to Remember
**Next = Previous + Previous Previous**

- `first` = ways to climb `i - 2` stairs.
- `second` = ways to climb `i - 1` stairs.
- `current` = ways to climb `i` stairs.

Example: `1, 2, 3, 5, 8, 13 ...`

## Example
Input: `n = 5`

Output: `8`

Explanation: There are 8 distinct ways to climb 5 stairs.

## Complexity
- **Time:** `O(n)` — One loop from 3 to n.
- **Space:** `O(1)` — Uses only three variables.

## Pattern
**Dynamic Programming (DP) — Fibonacci Pattern**
