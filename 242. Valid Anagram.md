# LeetCode 242 - Valid Anagram

## Question

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, otherwise return `false`.

### Example 1

```text
Input:
s = "anagram"
t = "nagaram"

Output:
true
```

### Example 2

```text
Input:
s = "rat"
t = "car"

Output:
false
```

---

# Concept

An anagram means:

- Both strings have the same length.
- Both strings contain the same characters.
- Every character appears the same number of times.

---

# Algorithm

### Step 1

Check whether both strings have the same length.

```java
if (s.length() != t.length())
    return false;
```

If the lengths are different, they cannot be anagrams.

---

### Step 2

Create a frequency array of size 26.

```java
int[] freq = new int[26];
```

Initially,

```text
Index : 0 1 2 3 ... 25
Letter: a b c d ... z
Value : 0 0 0 0 ... 0
```

Each index stores the count of one letter.

---

### Step 3

Traverse both strings together.

```java
for (int i = 0; i < s.length(); i++) {

    freq[s.charAt(i) - 'a']++;

    freq[t.charAt(i) - 'a']--;
}
```

What happens inside the loop?

- Take one character from the first string.
- Increase its count.
- Take the corresponding character from the second string.
- Decrease its count.

---

### Why `- 'a'`?

Characters are converted into array indices.

```text
'a' - 'a' = 0
'b' - 'a' = 1
'c' - 'a' = 2
...
'z' - 'a' = 25
```

So,

```java
freq[s.charAt(i) - 'a']
```

means

```text
a → freq[0]
b → freq[1]
c → freq[2]
...
z → freq[25]
```

---

### Step 4

Check every value in the frequency array.

```java
for (int count : freq) {

    if (count != 0)
        return false;
}
```

If every value is `0`, return `true`.

---

# Dry Run

```text
s = "ab"
t = "ba"
```

Initially

```text
a = 0
b = 0
```

### i = 0

```text
First String

a → +1

a = 1
```

```text
Second String

b → -1

b = -1
```

Current Frequency

```text
a = 1
b = -1
```

---

### i = 1

```text
First String

b → +1

b = 0
```

```text
Second String

a → -1

a = 0
```

Final Frequency

```text
a = 0
b = 0
```

All values are `0`.

Return `true`.

---

# Java Code

```java
class Solution {

    public boolean isAnagram(String s, String t) {

        if (s.length() != t.length())
            return false;

        int[] freq = new int[26];

        for (int i = 0; i < s.length(); i++) {

            freq[s.charAt(i) - 'a']++;

            freq[t.charAt(i) - 'a']--;
        }

        for (int count : freq) {

            if (count != 0)
                return false;
        }

        return true;
    }
}
```

---

# Time Complexity

```text
O(n)
```

# Space Complexity

```text
O(1)
```

---

# Key Points

- Check whether both strings have the same length.
- Create a frequency array of size 26.
- Increase the count for characters in the first string.
- Decrease the count for characters in the second string.
- If every value in the frequency array becomes `0`, the strings are anagrams.
- `freq[]` stores the frequency difference of each character.
- `'a'` is subtracted to convert characters into array indices (0 to 25).
