
## LeetCode 1572: Matrix Diagonal Sum

### Question
Given a square matrix `mat`, return the sum of the elements on its primary and secondary diagonals. If an element belongs to both diagonals, count it only once.

### Java Solution
```java
class Solution {
    public int diagonalSum(int[][] mat) {
        int n = mat.length;
        int sum = 0;

        for (int i = 0; i < n; i++) {
            sum += mat[i][i];
            sum += mat[i][n - i - 1];
        }

        if (n % 2 == 1) {
            // Avoid counting the center element twice
            sum -= mat[n / 2][n / 2];
        }

        return sum;
    }
}
```

### Approach
1. Traverse the matrix using a single loop.
2. Add `mat[i][i]` to calculate the primary diagonal sum.
3. Add `mat[i][n - i - 1]` to calculate the secondary diagonal sum.
4. If `n` is odd, subtract the center element because it was counted twice.
5. Return the total diagonal sum.

### Complexity
- Time: `O(n)`
- Space: `O(1)`
