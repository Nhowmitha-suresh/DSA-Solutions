# 713. Subarray Product Less Than K

## Question

Given an array of positive integers `nums` and an integer `k`, return the number of contiguous subarrays where the product of all elements is strictly less than `k`.

### Example

Input: `nums = [10,5,2,6], k = 100`

Output: `8`

## Approach

**Sliding Window + Two Pointers**

We maintain a window:

`[left ........ right]`

The product of the window should always be `< k`.

If the product becomes `>= k`, move `left` forward until the product becomes `< k` again.

## Algorithm

1. If `k <= 1`, return `0`.
2. Initialize `product = 1`, `left = 0`, and `count = 0`.
3. Move `right` from `0` to `n - 1`.
4. Add `nums[right]` to the product:
   `product *= nums[right]`
5. If `product >= k`, remove elements from the left:
   `product /= nums[left]`
   `left++`
6. When the window becomes valid, add:
   `count += right - left + 1`
7. Return `count`.

## Why Do We Divide?

When an element enters the window, we multiply:

`product *= nums[right]`

When an element leaves the window, we need to remove its contribution:

`product /= nums[left]`

Example:

`10 × 5 × 2 = 100`

Remove `10`:

`100 / 10 = 10`

So remember:

**ENTER → MULTIPLY**

**EXIT → DIVIDE**

## Why Do We Move Left?

If:

`product >= k`

the current window is invalid.

So we remove elements from the left until:

`product < k`

Example:

`[10,5,2]`

`product = 100`

`k = 100`

Since:

`100 >= 100`

Remove `10`:

`100 / 10 = 10`

New window:

`[5,2]`

Now:

`10 < 100`

The window is valid.

## Why `right - left + 1`?

After making the window valid, all subarrays ending at `right` are valid.

Example:

`[2,6]`

Valid subarrays ending at `6`:

`[6]`

`[2,6]`

Number of valid subarrays:

`right - left + 1`

So:

`count += right - left + 1`

## Memory Trick

### RIGHT = ADD

`right` moves forward:

`product *= nums[right]`

### TOO BIG = SHRINK

If:

`product >= k`

move `left`.

### LEFT = REMOVE

Remove the left element:

`product /= nums[left]`

Then:

`left++`

### VALID = COUNT

When:

`product < k`

add:

`count += right - left + 1`

## Easy Trick to Memorize

**RIGHT → MULTIPLY**

**LEFT → DIVIDE**

**BIG → SHRINK**

**VALID → COUNT**

Or remember:

**"Right adds, Left removes."**

## Pattern Recognition

Whenever you see:

**Count subarrays + Positive numbers + Product < K**

Think:

**SLIDING WINDOW**

## Main Pattern

`RIGHT → ADD → MULTIPLY`

`PRODUCT >= K → SHRINK`

`LEFT → REMOVE → DIVIDE`

`VALID → COUNT`

`COUNT = right - left + 1`

## Code

    class Solution {
        public int numSubarrayProductLessThanK(int[] nums, int k) {

            if(k<=1){
                return 0;
            }

            int n=nums.length;
            int count =0;
            int product=1;
            int left=0;

            for(int right=0;right<n;right++){
                product*=nums[right];

                while(product>=k){
                    product/=nums[left];
                    left++;
                }

                count+=right-left+1;
            }

            return count;
        }
    }

## Complexity

Time: `O(n)`

Space: `O(1)`

## Final One-Line Trick

**"Expand RIGHT, shrink LEFT, multiply when entering, divide when leaving, count the valid window."**
